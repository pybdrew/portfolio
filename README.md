## Featured Projects

### DadPath – Senior Capstone Project

DadPath is a full-stack web application designed to help expecting fathers prepare for parenthood through personal journaling, financial planning, and a centralized dashboard.

**Key Features**
- User registration and authentication
- Personalized dashboard
- Dad Log journaling
- Financial Planner with saved and editable responses
- PostgreSQL data persistence

**Technology Stack:** Angular, Java, Spring Boot, PostgreSQL, JWT, and BCrypt.
